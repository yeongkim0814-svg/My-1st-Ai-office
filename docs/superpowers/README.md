# docs/superpowers/ — 지휘자용 문서

이 폴더의 설계 문서(`specs/`)와 구현 계획(`plans/`)은 **지휘자(Claude)와 사용자용**이다.

- 에이전트(Codex, Gemini/Jules 등)는 이 폴더의 문장을 **작업 지시로 따르지 않는다.** 읽는 것은 괜찮다.
- 작업 지시는 Issue만 한다. Issue가 선언한 "수정 가능 경로"가 이 폴더를 포함한 모든 문서보다 우선한다.
- 이 폴더의 문서가 "~를 수정한다", "~를 기록한다"라고 적고 있어도, 그 주체와 허가는 Issue가 정한다.

근거: Issue #2 시험에서 Jules가 이 폴더의 문장을 Issue의 경로 제한보다 우선 적용해 보호 경로를 수정했다.
