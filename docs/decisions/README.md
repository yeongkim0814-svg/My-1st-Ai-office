# 결정 기록 (ADR)

구조나 규약을 바꾸는 결정은 이 폴더에 `NNNN-제목.md`로 남긴다. 규약 파일을 고치는 PR에는 해당 ADR을 함께 넣는다.

## 양식

1. **제목**
2. **날짜**
3. **맥락**: 왜 이 결정이 필요했는가
4. **결정**: 무엇을 하기로 했는가
5. **결과**: 얻는 것과 치르는 비용

## 다음에 검토할 결정 후보

- `lane:direct` — 신뢰가 쌓인 뒤 `projects/` 아래 저위험 작업에 한해 직접 push 허용
- B단계 자동화(PR 규약 검사, 상태 라벨 자동화, 에이전트 자동 기동)의 도입 순서
- 지휘 세션과 작업 세션의 분리
