# 포트폴리오·수익 옵션 탐색 (Issue #31, 예비)

범위: 포트폴리오가 되면서 수익·지원금으로 이어질 수 있는 옵션을 같은 기준으로 비교한다. 금액·나이·학교 등 개인 정보는 이 문서에 쓰지 않는다.
확인 수준: ◎ 직접 확인 / △ 검색 요약(2차) / ✕ 미확인·추정.

## 1. 평가 기준

| 기준 | 질문 |
|---|---|
| P 포트폴리오 가치 | 진학·인턴 지원서에 한 줄로 설명되고 링크로 보여줄 수 있는가 |
| C 소통량 | 사람과의 대화가 필수인가 (낮을수록 좋음) |
| M 4~8주 MVP | 혼자 4~8주 안에 외부에 보여줄 결과물이 나오는가 |
| R 수익·지원 경로 | 돈이나 지원금으로 이어지는 구체적 경로가 있는가 |
| O 소유권·AI 공개 | 저작권, 제3자 에셋, AI 사용 공개 위험 |
| D 외부 의존 | 심사, 계정, 결제 등 내가 통제 못 하는 것 |

## 4. 잠정 추천 (반증 조건 포함)

1. **옵션 4 + 옵션 5 결합: 공개 데이터 분석 노트북을 만들고 공모전 마감에 맞춰 제출**
   - 이유: 소통 낮음, MVP 빠름, 물리과 지망과 연결, 기존 코드·에셋 권리 문제 없음.
   - 반증: 4주 안에 외부 1명이 결과를 이해하지 못하거나 마땅한 마감 공모전이 없으면 옵션 1로 이동.
2. **옵션 1: 가상 실험실 중 실험 1개를 웹으로 최소 구현**
   - 이유: 지망 학과와 가장 직접적. 단 수익 경로가 약하므로 포트폴리오 목적임을 인정한다.
   - 반증: 기존 코드 권리가 불명확하거나 외부 시연자를 못 구하면 보류.

옵션 3은 이미 하는 일이므로 별도 시간 없이 기록만 남긴다. 옵션 2는 중단 상태 유지.

## 5. 이 문서의 한계

- 표의 평가는 대부분 추정(✕)이고 시간당 소득은 추정하지 않았다.
- 수익 경로가 확실한 옵션은 없다. 필요한 비용은 아르바이트가 받쳐 주고(채팅에서 별도 관리), 이 옵션들은 포트폴리오 가치로 고른 것이다.
- 한국 공모전 목록은 사용자가 사이트(링크커리어, 씽유)에서 직접 확인해 주는 편이 정확하다.
