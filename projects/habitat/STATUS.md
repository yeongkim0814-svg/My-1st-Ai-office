# habitat 현재 상태 (STATUS)

새 세션이나 다른 에이전트가 맥락을 빠르게 잡기 위한 짧은 문서다. 결정은 `DECISIONS.md`, 계획은 `ROADMAP.md`가 원본이고, 이 문서는 요약과 "다음에 누가 무엇을 하는지"만 적는다.

## 정리 규칙

- 이 문서는 **한 화면 분량**을 유지한다.
- "최근 변경"은 최근 5줄만 둔다. 6번째부터는 지우지 않고 `docs/archive/habitat-status-YYYY-MM.md`로 옮긴다(월별 파일).
- 단계(P0~P5)가 바뀌거나 매월 첫 주간 점검 때 정리한다. 주간 점검이 이 문서와 실제 상태를 비교해 갱신을 제안한다.
- 개인 정보·금액을 쓰지 않는다. 기기는 "기준 기기 A"로만 적는다.
