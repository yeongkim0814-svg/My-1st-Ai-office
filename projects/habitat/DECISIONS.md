# habitat(가칭) 설계 결정 기록

Issue #34. 사용자와 상의해 정한 것만 적는다. 바뀌면 지우지 말고 "변경" 줄을 추가한다.

## 확정

| # | 항목 | 결정 |
|---|---|---|
| D1 | 목적 | 수익이 아니라 하고 싶은 게임을 최선을 다해 완성. 포트폴리오·경험이 목적 |
| D2 | 공간 | 인터스텔라 쿠퍼 스테이션 같은 회전 원통 거주구. 원통 안쪽 바닥을 둘레 방향으로 벽 두 개가 나눠, 두 개의 반원 호(거주구역 Safe / 오염구역 Danger)가 된다. 각 구역은 원통 길이 전체에 걸친 띠이며 머리 위로 반대쪽 구역이 보인다 |
| D3 | 거주구역 | 아지트이자 출격 준비 공간. 자유로운 일상, 대화, 주민 요청, 판매. 자유도는 일부 축소 가능 |
| D4 | 오염구역 | PvE 레이드 지역. 생존 긴장은 여기서만. 기본은 회피(소리·시야·도구) + 제한적 전투 |
| D5 | 인벤토리 | Tarkov / Arena Breakout식 격자 인벤토리. 파밍한 아이템의 수요자는 거주구역 주민 |
| D6 | 플레이 방식 | (1) 레이드 파밍·판매·오염구역 퀘스트 (2) 거주구역 퀘스트·파밍·판매. 레이드는 필수가 아님 |
| D7 | 동기 | 전체를 관통하는 목표는 아직 없음. 주민의 요청과 플레이어의 호기심이 행동 동기. 퍼즐 중심이 아님 |
| D8 | 레이드 구조 | 열린 구조: 양쪽 벽 모두 출입 가능, 구역 안 탈출 지점 여러 개. 맵은 구간 모듈을 이어 붙여 길이를 늘린다 |
| D9 | 사망 | 보호 슬롯의 칸은 유지, 나머지는 죽은 자리의 가방에 남아 1회 회수 가능. 가방은 랜덤한 시간 뒤 사라짐. 남은 시간은 대략적 표시(임시 결정) |
| D10 | 시간 | A-lite: 실시간 시계 + 시간대별 주민 시간표. 필수는 밤낮 조명·분위기, 시간대별 대화·요청. 주민이 걸어 이동하는 연출은 후순위 |
| D11 | 시점 | 3D 1인칭 |
| D12 | 그래픽 | 미확정. 여러 스타일을 비교 후 결정(P0-M0). 애니메풍 캐릭터는 제외. Fate Trigger는 식생·바위·지형만 참고(주로 오염구역에 적용하는 안) |
| D13 | 물리 | 물리학과 무관해도 됨. 재미가 우선. 인공중력 특성은 쓸 수 있는 곳에만 쓴다 |
| D14 | 저장소 | 코드·문서는 공개 저장소 `habitat`, 에셋은 비공개 저장소 `habitat-assets`로 분리(2026-10-18, 이전 보류 Q1). 공개 저장소 코드 라이선스는 **미정**(지정 전까지 GitHub 기본값: 모든 권리 보유) |
| D15 | 엔진 버전 | Godot 4.7.x를 기준으로 한다(사용자의 개발 기기 에디터가 4.7.2). Codex 실행 환경은 4.6.3이므로 4.7 전용 기능은 당분간 쓰지 않는다. 검증 경로: (1) Codex 환경의 4.6.3 헤드리스(Codex 보고 기준), (2) 검토자(Claude) 세션이 공식 릴리스 `Godot_v4.7.2-stable_linux.x86_64.zip`을 내려받아 4.7.2 헤드리스로 같은 테스트를 실행한다(2026-10-18 세션에서 `--version`으로 4.7.2.stable과 4.6.3.stable 실행을 직접 확인함. 세션이 바뀌면 다시 내려받는다). 헤드리스로 확인되지 않는 것(렌더링, FPS, 터치 조작)은 사용자의 태블릿 4.7.2 에디터·기기 실행으로 확인한다. 기기에서 연 프로젝트 파일(`project.godot` 등)은 버전 표기가 바뀔 수 있으므로 의도 없이 커밋하지 않는다 |
| D16 | 플랫폼 | 개발: 안드로이드 태블릿. 플레이: 안드로이드 태블릿과 모바일. 조작은 터치(가상 스틱 + 화면 드래그 시점). 사용자의 태블릿을 성능 기준 기기로 쓴다. 스토어 등록·판매는 판매자의 나이·결제 요건을 모두 충족할 때만 |
| D17 | 회전 표현 | 월드는 고정하고 물체에 원심 가속도와 코리올리 가속도를 가하는 방식(B)으로 한다. 실제로 원통을 돌리는 방식(A)과 3초 자유비행 궤적이 0.3 mm 이내로 일치하며(R=1000 m, 바닥 중력 9.81 m/s²), 정적 충돌체를 매 틱 회전시킬 필요가 없다. 코리올리를 생략하면 3초 후 약 14.5 m 어긋나므로 생략하지 않는다. 근거: habitat PR #7(S1), 4.6.3·4.7.2 헤드리스 이중 검증. 성능 우위를 측정한 것은 아니다 |
