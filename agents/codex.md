# Codex

## 강점
초기 가설이며 관찰 기록으로 갱신한다.

- 범위가 분명한 구현 Issue를 독립적으로 수행하는 것 (가설).

## 맡기지 말 일
- 자기가 쓴 PR의 검토 (자기 검토 금지).
- 규약 파일(`docs/protocol/`, `agents/`, `.github/`, 진입 파일) 수정. 허점은 Issue로 제안한다.
- 병합.

## 쓰기 허용 경로
Issue가 선언한 경로뿐이다.

## 브랜치 접두어
`codex/` → `codex/<이슈번호>-슬러그`

## 기동 방법
Codex 웹/클라우드에서 이 레포를 연결한 뒤 표준 지시문을 입력한다.

> AGENTS.md를 읽고 Issue #N을 수행하라.

GitHub 댓글로 호출하는 자동 연동은 도입 전에 현재 공식 문서로 검증한다.
