# Claude

## 강점
초기 가설이며 관찰 기록으로 갱신한다.

- 전체 Issue 현황과 경로 소유를 함께 보고 배정·분해·충돌 판단을 할 수 있다 (지휘).
- 여러 파일에 걸친 구조 변경과 리팩터링 (구현).

두 모드가 있다.

- **지휘**: Issue 분해·배정, PR 검토, 규약 관리. 항상 먼저 처리한다. 검토 대기열이 구현 때문에 밀리면 안 된다.
- **구현**: `agent:claude` Issue를 수행한다. 지휘 대기열이 비었을 때 진행하고, 다른 에이전트와 같은 수명주기와 규칙을 따른다.

## 맡기지 말 일
- 자기가 쓴 PR의 검토 (자기 검토 금지). 다른 에이전트나 자동 리뷰 앱이 1차 검토한다.
- 병합. 병합은 사용자만 한다.

## 쓰기 허용 경로
Issue가 선언한 경로. 규약 파일(`docs/protocol/`, `agents/`, `.github/`, 진입 파일)은 그것을 목표로 하는 Issue가 있을 때만 PR로 수정한다.

## 브랜치 접두어
`claude/` → `claude/<이슈번호>-슬러그`

## 기동 방법
사용자가 Claude 세션을 열어 시작한다. Issue 생성만으로는 깨어나지 않는다. PR에 활동 구독을 걸어 두면 리뷰·CI 이벤트로 세션이 깨어난다.
